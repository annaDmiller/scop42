| Prefix    | Meaning                               | Example               |
|---        |---                                    |---                    |
| `v`       | Vertex position                       | `v 1.0 2.0 3.0`       |
| `vt`      | Texture coordinate                    | `vt 0.5 0.5`          |
| `vn`      | Vertex normal                         | `vn 0.0 1.0 0.0`      |
| `f`       | Face definition                       | `f 1 2 3`             |
| `o`       | Object name                           | `o Cube`              |
| `g`       | Group name                            | `g Body`              |
| `mtllib`  | Material library reference            | `mtllib model.mtl`    |
| `usemtl`  | Material to use for subsequent faces  | `usemtl Red`          |
| `s`       | Smoothing group                       | `s 1`                 |


v 0.0 1.0 0.0
v -1.0 -1.0 0.0
v 1.0 -1.0 0.0

f 1 2 3

it means
Vertex 1 = ( 0.0,  1.0, 0.0)
Vertex 2 = (-1.0, -1.0, 0.0)
Vertex 3 = ( 1.0, -1.0, 0.0)
The f 1 2 3 line tells you to connect these three vertices to form a triangle.

(Notice that OBJ indices start at 1, whereas C++ arrays and vectors start at 0.)
